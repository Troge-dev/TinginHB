1. Executive Summary & Critical Data Discoveries

A full forensic and descriptive analysis was performed across all 7 local datasets (11,446 files totaling ~716 MB) and planned external cohorts. Several critical findings were uncovered that directly impact pipeline architecture, model training validity, and commercial startup viability:

  1. Catastrophic Label Contamination in eye-conjunctiva (22.5% Error Rate): The public Kaggle dataset nadiwidi/eyeconjunctiva (218 images) was created by naively assigning all 95 Indian subjects from EYES-DEFY-ANEMIA to Resized Anemia and all 123 Italian subjects to Resized Non Anemia. In reality, 28.4% (27/95) of the Indian cohort is clinically healthy, and 17.9% (22/123) of the Italian cohort is clinically anemic. Using this dataset for classification introduces extreme label noise.
  2. 100% Byte-for-Byte Dataset Duplication: data/raw/fingernail/fingernail-anemia-classified (4,260 images) and data/raw/fingernail/fingernail-anemia-ghana (4,260 images) are identical duplicate files (identical filenames, byte hashes, and directory layout), wasting ~25.7 MB of storage and misrepresenting cohort diversity.
  3. Severe Data Leakage Risk in Fingernail Datasets: While fingernail-anemia-classified has 4,260 PNG files, there are only 556 unique base subjects (~7.6 synthetic augmentations per subject). In anemia-fingernail-ayush, although 1,777 images are present, there are only 8 unique anemic individuals (90 images) and 221 healthy individuals. A naive random train/val/test split without subject-level grouping will produce massive data leakage.
  4. Typographical Label Bug: 44 fingernail images carry the prefix Anmeic-Fin- instead of Anemic-Fin-. Naive prefix filtering (startswith('Anemic')) will unintentionally discard 38 unique patients.
  5. Corrupt iCCP Headers in Segmentation Masks: All 644 PNG segmentation masks in EYES-DEFY-ANEMIA contain invalid iCCP embedded color profile checksums. In modern Pillow (v10+), attempting to open these masks throws SyntaxError: broken PNG file (bad header checksum in b'iCCP') unless ImageFile.LOAD_TRUNCATED_IMAGES = True or headers are sanitized.
  6. Commercial Licensing Restriction (Copyleft): Via mobus MCP verification, the core segmentation dataset EYES-DEFY-ANEMIA is governed by CC BY-SA 4.0 (ShareAlike). Any derived models or weights distributed commercially must be licensed under equivalent terms.

**Data Quality Alert: Inconsistent Anemia Ground-Truth Thresholds**:
In `anemia-detection-dataset`, the maximum Hb observed in the `Anaemic = Yes` cohort is **14.5 g/dL**, whereas the minimum Hb observed in the `Anaemic = No` cohort is **10.3 g/dL**. For modeling, **discard the categorical `Anaemic` label and derive labels deterministically from continuous `Hb`**.

  • Segmentation Masks: 644 .png files (palpebral, forniceal, and combined) at $800 \times 1067$ resolution.

📌 IMPORTANT
**Key Scientific Finding: The Critical Need for Subungual Segmentation & Baseline Normalization**:
In unsegmented nail crops, the difference in Erythema Index between anemic and healthy fingernails is **statistically insignificant ($p = 0.314$)**. Surrounding skin, background pixels, cuticles, and melanin variations overpower the subtle nail bed capillary signal. This proves that end-to-end classifiers trained on raw crops will learn background spurious features. Accurate segmentation of the subungual nail plate via **YOLOv8n-seg** followed by **periungual contrast normalization** ($\Delta \text{EI} = \text{EI}_{\text{nail}} - \text{EI}_{\text{skin}}$) is scientifically mandatory.
